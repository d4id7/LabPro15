# Практическая работа №15. JSON: сериализация и десериализация

## Контрольные вопросы

**ПР15. Ответы на контрольные вопросы**

1. **Что такое JSON и для чего он используется?**
   JSON (JavaScript Object Notation) — это текстовый формат для представления структурированных данных. Он используется для обмена данными между приложениями, хранения конфигов и передачи информации по сети (например, в веб-API). Его главные преимущества — человекочитаемость и независимость от языка программирования.

2. **Чем отличается `Serialize` от `Deserialize`?**
   `Serialize` преобразует объект C# в JSON-строку (текстовое представление). `Deserialize` выполняет обратную операцию — восстанавливает типизированный объект C# из JSON-строки.

3. **Почему результат `JsonSerializer.Serialize(...)` имеет тип `string`?**
   Потому что JSON — это текстовый формат. Результат сериализации — это JSON-строка, которую можно сохранить в файл, передать по сети, записать в базу данных или использовать любым другим способом работы с текстом.

4. **Как сохранить полученную JSON-строку в файл и затем восстановить из неё объект?**
   Для сохранения используется `File.WriteAllText(path, jsonString)`. Для восстановления: сначала читаем текст через `File.ReadAllText(path)`, затем десериализуем его в объект с помощью `JsonSerializer.Deserialize<T>(jsonString)`.

5. **Можно ли сериализовать `List<T>`? Что получится при сериализации списка объектов?**
   Да, `List<T>` сериализуется. Результатом будет JSON-массив — строка вида `[{...}, {...}, {...}]`, где каждый объект списка представлен как JSON-объект внутри квадратных скобок.


6. **Что произойдёт, если JSON некорректен или не соответствует ожидаемому типу?**
   Среда выполнения (runtime) выбросит исключение `JsonException` (или его подтип `JsonReaderException` при ошибках парсинга). Это произойдёт во время выполнения программы, а не на этапе компиляции.

7. **Почему JSON удобно использовать для хранения данных между запусками программы?**
   JSON удобен, потому что его легко читает человек (в отличие от бинарных форматов), данные имеют чёткую структуру, формат кроссплатформенен (работает на любых языках и ОС), и из него можно легко восстановить исходный тип данных программы.
